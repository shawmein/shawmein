## 🚩 提交纪律 · Commit Discipline (三大纪律八项注意)

1. 一切 commit 听指挥，`git commit -m "为人民服务"`
2. 不拿群众一行代码：不复制粘贴未标注来源的 Stack Overflow 答案
3. 一切 force push 要归公：`--force` 须经组织批准
4. 说话和气，Code Review 要文明
5. 损坏 main 分支要赔偿
